# 🌸 시의 마음을 읽다
## 한국 근대시 감정 분석 웹사이트

### 1. 프로젝트 소개

**「시의 마음을 읽다」**는 한국 근대시 15편에 나타나는 감정을 분석하고 시각화하는 감성컴퓨팅 프로젝트이다.

시의 감정을 단순히 감상하는 데서 나아가, 감정 어휘를 데이터로 변환하여 작품별 감정 분포를 비교할 수 있도록 구현하였다. 또한 컴퓨터가 감지한 감정과 사람이 문학적으로 해석한 감정 사이에 어떤 차이가 발생하는지 살펴보았다.

이 프로젝트는 **감정 사전 기반 규칙 분석**을 사용하며, 별도의 서버나 API 키 없이 웹브라우저에서 실행된다.

### 2. 웹사이트 주소 및 사용 방법

**웹사이트 주소**

https://byten324-dot.github.io/korean-poetry-emotion-map/

**사용 방법**

1. 웹사이트에 접속한다.
2. 상단의 작품 선택 메뉴에서 분석하고 싶은 시를 선택한다.
3. 시 원문에서 감정 단어가 강조된 부분을 확인한다.
4. 감정별 비율과 지배 정서를 확인한다.
5. 행별 감정 분석과 감정 흐름 차트를 살펴본다.
6. 비슷한 감정을 가진 다른 시 3편을 추천받는다.
7. 전체 작품의 감정 분포를 히트맵으로 비교한다.
8. 직접 작성한 시나 문장을 입력하여 감정 분석을 실행할 수도 있다.

### 5. 감정 분석 방법

#### 5-1. 감정 단어 탐색

시 원문에 감정 사전에 등록된 단어가 포함되어 있는지 검사한다.

예를 들어 원문에 '사랑'이라는 단어가 등장하면 사랑 범주의 감지 횟수가 증가한다.

#### 5-2. 중복 계산 방지

여러 감정 단어가 동일한 문자열 위치에서 겹치는 경우, 긴 단어를 우선 선택하여 중복 계산을 방지한다.

단, 이 방식은 문자열의 위치가 겹치는 경우만 처리하므로 문맥에 따른 의미 중복까지 해결하지는 못한다.

#### 5-3. 감정 비율 계산

감정 비율은 다음과 같이 계산한다.

**감정 비율(%) = (해당 감정 단어 감지 횟수 ÷ 전체 감정 단어 감지 횟수) × 100**

예를 들어 사랑 3회, 슬픔 2회, 그리움 5회가 감지되었다면 전체 감지 횟수는 10회이다.

- 사랑: 30%
- 슬픔: 20%
- 그리움: 50%

이때 지배 정서는 가장 높은 비율을 가진 **그리움**이다.

감정 단어가 전혀 감지되지 않으면 지배 정서를 '감정 단어 미감지'로 표시한다.

#### 5-4. 행별 감정 분석

시를 줄바꿈 기준으로 분리한 뒤 각 행에 동일한 감정 분석 함수를 적용한다.

각 행에서 감지된 감정과 횟수를 표시하며, 이를 색상 막대 형태의 감정 흐름 차트로 나타낸다.

#### 5-5. 유사한 시 추천

각 작품의 8개 감정 비율을 하나의 벡터로 구성한다.

두 작품의 감정 벡터에 **코사인 유사도**를 적용하여 감정 분포가 비슷한 작품 3편을 추천한다.

코사인 유사도는 감정 비율의 유사성을 비교하는 수치이며, 문학적 주제나 작품의 전체 의미가 동일하다는 뜻은 아니다.

### 7. 컴퓨터 분석과 문학적 해석의 차이

감정 사전 기반 분석은 감정 단어의 빈도를 계산할 수 있지만, 시의 문학적 의미를 완전히 이해하지는 못한다.

다음은 이러한 차이가 발생할 수 있는 대표적인 사례이다.

#### 사례 1. 김소월 「진달래꽃」

**주요 표현:** '죽어도 아니 눈물 흘리오리다.'

**문학적 해석**

화자는 눈물을 흘리지 않겠다고 말하지만, 이 표현은 오히려 이별의 슬픔을 강하게 전달한다. 감정을 드러내지 않으려는 태도 자체가 슬픔의 깊이를 보여 주는 것으로 해석할 수 있다.

**감정 분석의 한계**

현재 분석기는 '눈물'을 슬픔 단어로 감지하지만, '아니'라는 부정 표현과 문장 전체의 의미를 별도로 분석하지 않는다.

**개선 방안**

부정 표현과 감정 단어의 관계를 파악하는 문장 단위 분석을 추가한다. 반어 표현에 관한 규칙을 구축하는 방법도 고려할 수 있다.

#### 사례 2. 김소월 「먼 후일」

**주요 표현:** '잊었노라'

**문학적 해석**

화자는 잊었다는 말을 반복하지만, 작품 전체를 읽으면 실제로는 잊지 못하는 그리움이 드러난다. 표면적인 진술과 내면의 감정이 어긋나는 반어적 표현이다.

**감정 분석의 한계**

'잊었노라' 자체가 현재 감정 사전에 등록되어 있지 않으므로, 작품의 핵심 정서가 충분히 반영되지 않을 수 있다.

**개선 방안**

반복되는 표현과 작품 전체의 맥락을 함께 분석한다. 단어 단위 분석에 문장 및 작품 단위의 의미 분석을 결합할 필요가 있다.

#### 사례 3. 한용운 「나룻배와 행인」

**주요 표현:** '나는 나룻배 / 당신은 행인'

**문학적 해석**

나룻배와 행인의 관계는 헌신적인 사랑과 기다림을 상징한다. 나룻배는 상대를 위해 자신을 내어 주는 존재로 해석된다.

**감정 분석의 한계**

'사랑'이라는 단어가 직접 등장하지 않아도 작품 전체에서는 사랑의 정서가 중요하게 나타날 수 있다. 단순한 어휘 분석은 이러한 상징 관계를 충분히 반영하지 못한다.

**개선 방안**

상징과 비유를 해석하는 의미 분석을 도입한다. 작품별 핵심 상징어와 감정의 관계를 별도로 정리하는 방법도 가능하다.

#### 사례 4. 윤동주 「자화상」

**주요 표현:** '미워저', '가엾어집니다', '그리워집니다'

**문학적 해석**

화자는 자기 자신에 대한 미움과 연민, 그리움을 동시에 드러낸다. 서로 다른 감정이 한 대상에게 향한다는 점이 중요하다.

**감정 분석의 한계**

현재 분석기는 각 단어를 개별 감정 범주에 연결한다. 그러나 그 감정들이 모두 자기 자신을 향한다는 사실이나 감정이 변화하는 과정은 충분히 파악하지 못한다.

**개선 방안**

감정의 대상과 주체를 식별하는 기능을 추가한다. 작품 전체에서 감정이 어떻게 변화하는지 분석하는 방법도 필요하다.

**검증 사례에 관한 참고**

위 사례는 작품의 문학적 의미와 현재 분석 방식의 구조적 차이를 설명한 것이다. 실제 감정 비율은 웹사이트에 구현된 감정 사전과 원문 표기에 따라 달라지므로, 제출 전 각 작품을 선택해 표시되는 결과와 설명을 대조해야 한다.

### 8. 분석 방법의 한계

본 프로젝트에는 다음과 같은 한계가 있다.

**첫째, 단어의 문맥을 충분히 반영하지 못한다.**  
같은 단어라도 문장에 따라 서로 다른 감정을 나타낼 수 있다.

**둘째, 반어와 부정 표현을 정확하게 처리하기 어렵다.**  
'눈물을 흘리지 않는다'와 '눈물을 흘린다'는 의미가 다르지만, 단순 단어 탐색에서는 같은 감정 단어가 감지될 수 있다.

**셋째, 은유와 상징을 이해하기 어렵다.**  
시에서는 자연물이나 사물이 감정을 대신 표현하는 경우가 많다.

**넷째, 감정 사전의 범위가 제한적이다.**  
사전에 등록되지 않은 단어는 분석 결과에 반영되지 않는다.

**다섯째, 역사적 표기 차이에 영향을 받는다.**  
근대시의 원문 표기와 현대어 표기가 다르면 동일한 의미라도 감지 결과가 달라질 수 있다.

**여섯째, 감정 비율은 작품의 실제 감정 강도를 뜻하지 않는다.**  
감정 단어가 많이 등장한다고 해서 반드시 그 감정이 문학적으로 가장 중요하다고 볼 수는 없다.

따라서 본 프로젝트의 분석 결과는 **문학적 해석을 보조하는 참고 자료**로 활용해야 한다.

### 9. 개발 환경

- **HTML5:** 웹사이트의 구조 구현
- **CSS3:** 디자인 및 반응형 화면 구현
- **JavaScript:** 감정 분석, 그래프, 추천 기능 구현
- **GitHub:** 소스 코드 저장 및 버전 관리
- **GitHub Pages:** 정적 웹사이트 배포

별도의 서버, 데이터베이스, 유료 API는 사용하지 않았다.

### 10. AI 활용 내역

본 프로젝트를 진행하면서 생성형 AI인 **ChatGPT**의 도움을 받았다.

주요 활용 내용은 다음과 같다.

1. 프로젝트의 전체 구조와 화면 구성 구상
2. HTML, CSS, JavaScript 코드 초안 작성
3. 감정 사전 기반 분석 방식 설계
4. 감정 비율 계산 및 시각화 기능 구현
5. 코사인 유사도 기반 작품 추천 기능 작성
6. 작품별 문학적 해석 초안 정리
7. 분석의 한계와 검증 사례 작성
8. README 문서 초안 작성

생성형 AI는 코드와 설명을 작성하는 보조 도구로 활용하였다. 특히 시 원문의 정확성, 작품 정보의 신뢰성, 감정 분석 결과의 적절성은 AI가 생성한 내용만으로 보장되지 않으므로 별도 검토가 필요하다.

### 11. 프로젝트를 통해 알게 된 점

이번 프로젝트를 통해 문학 작품의 감정을 컴퓨터가 처리할 수 있는 데이터로 변환하는 과정을 살펴볼 수 있었다.

감정 사전을 활용하면 작품별 감정 단어의 분포를 계산하고 시각적으로 비교할 수 있다. 또한 서로 다른 작품 사이의 감정 분포가 얼마나 유사한지 수치로 표현할 수도 있다.

하지만 시의 감정은 단어의 빈도만으로 결정되지 않는다. 반어, 상징, 비유, 시대적 배경과 같은 문학적 요소가 감정 해석에 중요한 영향을 준다.

따라서 감성컴퓨팅에서 중요한 것은 단순히 감정을 분류하는 것뿐 아니라, **분석 결과의 한계를 이해하고 사람의 해석과 함께 활용하는 것**이라고 생각한다.

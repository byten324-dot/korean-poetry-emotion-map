# 시의 마음을 읽다
## 한국 근대시 15편의 감정 분석 웹앱

2026학년도 2학기 감성컴퓨팅 개인 프로젝트

한국 근대시 15편을 대상으로 감정 사전 기반의 정량 분석을 수행하고, 그 결과를 문학적 해석과 비교하는 웹 애플리케이션이다.

## 1. 웹앱 주소 및 사용 방법

### 웹앱

### GitHub 저장소

https://github.com/byten324-dot/korean-poetry-emotion-map

### 사용 방법

1. 웹앱에 접속한다.
2. 작품 목록에서 분석할 시를 선택한다.
3. 시 전문과 감정별로 강조된 시어를 확인한다.
4. 감정 비율, 지배 정서, 주제 및 문학적 해석을 비교한다.
5. 레이더 차트와 행별 감정 흐름을 확인한다.
6. 시어–감정–주제 다이어그램을 확인한다.
7. 유사 감성 시 추천을 이용하여 다른 작품으로 이동한다.
8. 전체 비교 히트맵으로 작품별 감정 분포를 비교한다.
9. 나의 시 분석 기능에서 직접 작성한 시를 분석할 수 있다.

별도의 프로그램 설치, 회원가입, API 키가 필요하지 않다.

## 3. 감정 범주 정의 및 분석 방법

### 감정 범주

총 8개의 감정 범주를 사용하였다.

| 감정 | 정의 | 대표 어휘 |
|---|---|---|
| 사랑 | 타인이나 대상에 대한 애정과 소중히 여기는 마음 | 사랑, 애정, 연모 |
| 슬픔 | 상실과 이별, 고통에서 발생하는 비애와 서러움 | 눈물, 설움, 슬픔 |
| 그리움 | 멀어진 사람이나 지나간 시간과 장소를 다시 만나고 싶은 마음 | 추억, 그리워, 기다리 |
| 희망 | 미래의 변화와 회복을 기대하며 앞으로 나아가려는 마음 | 희망, 내일, 새로운 |
| 평온 | 갈등과 긴장이 줄어들어 안정되고 고요한 상태 | 고요, 평화, 가만히 |
| 기쁨 | 즐거움과 만족, 긍정적인 경험에서 생기는 밝은 감정 | 행복, 웃음, 좋아 |
| 분노 | 부당함이나 갈등에 대한 반발, 미움과 원망의 감정 | 미워, 원망, 시샘 |
| 불안 | 불확실한 상황이나 위협 앞에서 느끼는 걱정과 두려움 | 걱정, 공포, 방황 |

| 사랑 | 13 |

각 범주에 10개 이상의 감정 어휘를 포함하였다.

### 감정 사전 개선 내용

한국 근대시의 표현과 한자 표기를 고려하여 감정 사전을 구성하였다.

- 그리움 범주에 追憶, 憧憬 등을 포함하였다.
- 희망 범주에 希望, 來日 등의 한자 표기를 포함하였다.
- 슬픔 범주에 쓸쓸, 불설워 등을 추가하였다.
- 희망 범주에 살자, 믿습니다 등을 추가하였다.
- 불안 범주에 방황, 막막 등의 표현을 추가하였다.
- 길의 방황과 방향 상실을 반영하기 위해 어디로 갈까, 오라는 곳이 없어, 갈 길은 하나 없 등의 구절 단위 표현을 추가하였다.

이러한 표현은 모든 문맥에서 동일한 감정을 의미하지는 않으므로 사전 기반 분석의 한계로 함께 기록하였다.

### 분석 절차

1. 시 본문을 행 단위로 분리한다.
2. 감정 사전과 본문의 문자열을 비교한다.
3. 긴 표현부터 우선적으로 감지한다.
4. 동일한 위치의 감정 어휘가 중복 계산되지 않도록 한다.
5. 감정별 감지 횟수를 합산한다.
6. 전체 감지 횟수에 대한 감정별 비율을 계산한다.
7. 가장 높은 비율을 가진 감정을 지배 정서로 표시한다.
8. 계산 결과와 별도로 작품의 문학적 주제 및 해석을 제시한다.

### 감정 비율 계산

감정 비율(%) = 해당 감정의 감지 횟수 / 전체 감정 감지 횟수 × 100

표시 비율은 소수점 첫째 자리까지 계산한다.

반올림 과정에서 발생하는 합계 오차는 최대 나머지 방식으로 보정한다.

감정 어휘가 하나도 감지되지 않는 경우에는 임의의 감정을 부여하지 않고 감지 없음으로 표시한다.

### 유사도 계산

작품별 8차원 감정 비율 벡터를 사용한다.

코사인 유사도를 계산하여 감정 분포가 가장 유사한 작품 3편을 추천한다.

코사인 유사도 = 두 벡터의 내적 / 두 벡터 크기의 곱

유사도는 0~100%로 표시한다.

감정 분포가 비슷하다는 것은 작품의 문학적 의미가 완전히 동일하다는 뜻은 아니다.

### 구현 기능

필수 기능:

- 작품 목록
- 시 전문 및 감정 시어 강조
- 감정 비율 분석
- 행별 감정 분석
- 지배 정서, 주제 및 문학적 해석

기본 기능:

- 감정 프로필 레이더 차트
- 행별 감정 흐름 차트
- 시어–감정–주제 다이어그램

- 직접 입력한 시 분석

## 4. 정량 분석과 문학적 해석의 검증 사례

### 사례 1. 진달래꽃

정량 분석:
눈물이라는 어휘를 통해 슬픔이 감지된다.

문학적 해석:
이별의 슬픔뿐 아니라 상대에 대한 사랑과 감정의 절제가 중요하다.

차이의 원인:
감정 사전은 아니 눈물 흘리오리다라는 부정 표현과 반어적 의미를 충분히 분석하지 못한다.

개선 방향:
부정 표현의 범위를 파악하고 앞뒤 문맥을 함께 분석하는 규칙을 추가한다.

### 사례 2. 산유화

정량 분석:
좋아라는 어휘가 기쁨으로 분류된다.

문학적 해석:
작품 전체에는 자연의 순환과 존재의 고독, 평온함이 함께 나타난다.

차이의 원인:
꽃과 자연의 상징적 의미, 혼자라는 상황을 단순 감정 사전이 충분히 반영하지 못한다.

개선 방향:
자연 이미지와 고독을 나타내는 표현을 문맥 단위로 분석한다.

### 사례 3. 나룻배와 행인

정량 분석:
기다리라는 표현은 그리움으로, 짓밟이라는 표현은 분노로 감지된다.

문학적 해석:
작품의 핵심은 상대에 대한 헌신적이고 조건 없는 사랑이다.

차이의 원인:
짓밟는 행위와 그 행위에 대한 화자의 감정은 서로 다를 수 있다. 사전 기반 분석은 행위의 주체와 화자의 태도를 구분하기 어렵다.

개선 방향:
행위의 주체와 대상, 화자의 반응을 함께 분석한다.

### 사례 4. 자화상

정량 분석:
미워, 가엾, 그리워, 追憶 등의 표현을 통해 분노와 슬픔, 그리움이 감지된다.

문학적 해석:
작품의 핵심은 자기 자신에 대한 복합적인 성찰과 내적 갈등이다.

차이의 원인:
감정 사전은 감정의 대상이 타인인지 자기 자신인지 구분하지 못한다.

개선 방향:
대명사와 감정의 대상을 연결하고 작품 전체의 감정 변화를 분석한다.

### 사례 5. 엄마야 누나야

정량 분석:
살자라는 표현이 반복되어 희망이 감지된다.

문학적 해석:
작품 전체의 분위기는 가족과 자연 속에서 느끼는 따뜻함과 평온함에 가깝다.

차이의 원인:
금모래빛과 갈잎의 노래 같은 자연적 이미지는 직접적인 감정 어휘가 아니기 때문에 감정 사전에서 감지되지 않는다.

개선 방향:
감각적 이미지와 자연적 상징을 분석할 수 있는 문맥 기반 모델을 도입한다.

## 5. 한계 및 개선 방향

### 한계

첫째, 감정 사전 기반 분석은 단어의 등장 횟수를 중심으로 계산하기 때문에 반어와 역설을 충분히 이해하지 못한다.

둘째, 감정 어휘의 등장 여부와 실제 화자의 감정은 다를 수 있다.

셋째, 한국 근대시의 옛 표기와 한자 표현, 시대적 배경을 완전히 반영하기 어렵다.

넷째, 반복되는 시어는 감정 비율에 큰 영향을 줄 수 있지만 문학적 중요도와 반드시 일치하지는 않는다.

다섯째, 일부 구절 단위 감정 어휘는 특정 작품에 적합하지만 다른 문맥에서는 오분류를 일으킬 수 있다.

여섯째, 감정 사전에 없는 표현은 분석 결과에 반영되지 않는다.

일곱째, 일부 작품의 최초 발표 기록에는 자료 간 차이가 존재하므로 확인된 시집 수록 기록과 구분하여 표시하였다.

### 개선 방향

- 부정 표현과 반어를 처리하는 규칙 추가
- 형태소 분석을 활용한 감정 어휘 감지
- 문맥 기반 감정 분류 모델 활용
- 화자와 감정 대상의 관계 분석
- 한자 및 옛 표기 변환 사전 확대
- 감정 어휘의 중요도에 따른 가중치 적용
- 다양한 작품을 활용한 감정 사전의 일반화 검증
- 최초 발표 기록 및 원문 판본에 대한 추가 서지 조사

### 기술 구성

- HTML5
- CSS3
- JavaScript ES2020 이상
- SVG 기반 시각화
- GitHub Pages

별도의 서버나 데이터베이스 없이 브라우저에서 모든 분석을 수행한다.

## 6. AI 도구 사용 내역

### ChatGPT

- 웹앱 구조 및 사용자 인터페이스 설계
- HTML, CSS, JavaScript 코드 작성
- 감정 사전과 분석 알고리즘 구성
- 감정 비율 및 코사인 유사도 계산 구현
- 차트 및 히트맵 구현
- 작품 해석 초안 작성
- 검증 사례와 개선 방향 정리
- README 초안 작성

### Google Gemini

- 한국 근대시 원문 출처 조사
- 작품별 발표 연도 및 시집 수록 기록 조사
- 시인 사망 연도 확인 지원
- 출처 주소의 오류 검토
- 발표 기록이 상충하는 작품에 대한 추가 조사

### AI 활용에 대한 주의 사항

AI가 제공하는 자료에는 원문 표기, 발표 기록 및 출처 주소의 오류가 포함될 수 있다.

따라서 원문 출처와 발표 기록 참고 자료를 별도로 표시하였으며, 불확실한 발표 기록은 확정된 사실과 구분하였다.

정량 분석 결과는 JavaScript 감정 분석 엔진에서 계산하며 AI가 임의로 감정 비율을 생성하지 않는다.

문학적 해석과 검증 사례는 AI의 초안을 바탕으로 제출 전 작성자가 직접 검토하고 수정한다.

## 프로젝트의 의의

이 프로젝트는 문학 작품의 감정을 수치화하는 과정과 문학적 해석의 차이를 비교하는 데 목적이 있다.

감정 분석 결과를 시각화함으로써 작품 간 감정 분포의 차이를 확인할 수 있으며, 정량 분석만으로는 설명하기 어려운 문학적 의미도 함께 살펴볼 수 있다.

감정 분석 기술은 문학적 해석을 대체하는 것이 아니라 작품을 다양한 관점에서 이해하도록 돕는 보조 수단으로 활용될 수 있다.
